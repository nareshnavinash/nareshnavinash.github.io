Credits

This 3D world is built on folio-2025 by Bruno Simon, released under the MIT license.
I’ve customized it with my own career data, content, and personal branding while keeping the incredible game mechanics, vehicle physics, and interactive world intact.

Tech Stack

The portfolio uses Three.js with WebGPU rendering, Rapier for physics, and Howler.js for audio.
Music by Kounine (Linktree), released under CC0 license.
